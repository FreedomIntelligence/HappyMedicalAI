# Happy Medical AI

**Built on the framework of large language models (LLMs), with medical scenarios as the entry point, covering practical cases and technical explanations.**

This project adopts a "scenario-driven + technology-focused" approach to help medical learners and practitioners understand and master the practical applications of AI in healthcare.

## 🌟 Project Logic

1. **Start with practical cases**: Cover real medical scenarios (e.g., case analysis, clinical decision-making, follow-up management).
2. **Map scenarios to model hierarchies**: Correspond to **general → medical → specialty → disease-specific large language models**.
3. **In-depth technical explanations**: Begin with technical needs derived from real-scenario problems, and detail practical, high-learning-value application technologies and their corresponding scenarios.
4. **Form an overall framework**: Establish a systematic path from "clinical application" to "AI technology".

## 🚀 Learning Approach

1. Start with **cases** → First review real scenarios.
2. Align with **model classifications** → Identify the appropriate model type.
3. Dive into **technical explanations** → Learn prompt design, model calling, and fine-tuning methods.
4. Complete **practical training** → Apply in clinical practice or research.
5. Share **feedback and optimization** → Co-build with the community.
