# 第二章 通用大模型的医疗普适性：提示词工程实践

在通用大语言模型和医疗大语言模型中，虽然模型训练学习的医学知识不够深入、系统、专业，但是在正确的引导和一些专业的技术调中，依然能凭借强大的推理能力输出相对可靠的结果，但应用于临床场景治疗辅助依然欠妥，需要专业医疗人士进行筛选。
> 提示词的相关技术，更好调用AI能力解决医疗场景问题
>
> 明确专家身份，明确指令给予AI定位---Expert prompt
>
> 反思逻辑漏洞，指导AI反思自己思考逻辑性和答案自洽性---reflective prompt
>
> 逻辑链引导正确思考，逻辑链条帮助AI思考---chain-of-thought
>
> 逻辑树助力多线路求索，提升复杂病例的处理能力---tree-of-thought
>
> 微小示例帮助标准解答，完善答案形式和逻辑学习---few-shot

## 一、Expert prompt-AI医疗专业化

专业性缺失，专业知识运用错误等问题，是常见问题，对于通用大语言模型来说，好比问一位学识渊博却涉猎不深，且听不大懂平常话的大专家，所以，需要我们在指令中为这位大专家定位一下，指示AI自己回答问题的身份、专业领域，更方便AI找取专业知识，精准定位知识库范围。

Expert prompt 对于AI来说可以更好地回答专业知识性问题，减少回答专业领域问题时错用医疗其他领域知识

[示例expert prompt](https://eegb6fzscd.feishu.cn/wiki/CYgMw1g4KiFKfPksj3FcZIYongg?from=from_copylink)

Expert 给予AI人为职业及身份设定，我们可以详细告诉AI解决医疗问题所需要的专业身份和专业知识范围或专业技能名称，帮助AI在思考推理时更好定位专业信息和专业范围，选取适合场景的资料进行学习，最终可以提供合适的专业的对实际诊疗有帮助的建设性意见

## 二、Reflective prompt-AI反思自我改进思路

AI很容易输出具有渐层谬误的回答，当我们使用反思指令时，可以引导AI反思自身问题，改正此类问题，同时，反思过程也可以帮助AI改进思路，创新解决途径，实现结果的飞跃。

基于专业文献和临床经验，我为你设计了一个用于反思肺结节诊疗方案的**结构化提示框架**。该框架融合了**CLEAR提示原则**、**临床决策逻辑链**与**医疗AI评测维度**，能系统性地引导模型审视诊断推理中的潜在问题。

### 🎯 反思框架与核心维度

你可以使用以下表格中的维度，对初步的诊疗方案进行系统性审视。这些维度涵盖了从诊断逻辑到伦理安全的多个关键方面。

| 维度               | 核心审视点 (供提示词调用)                                    | 参考案例/方法                                                |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **诊断逻辑严谨性** | 1. 鉴别诊断是否充分？恶性概率估算依据？<br>2. 对“矛盾信息”（如良性特征）的考量与权重？<br>3. 是否遵循“症状→鉴别诊断→证据验证→结论”的逻辑链？ | 肺结节误诊分析中，常因对“快速进展”这一与典型恶性肿瘤不符的特征、或与PET-CT轻度代谢增高等矛盾信号权衡不足导致误判。 |
| **证据链完整性**   | 1. 关键临床信息（如听诊结果、特定影像学细节）是否缺失？<br>2. 建议的检查（如活检、PET-CT）与诊断假设的关联性？<br>3. 是否整合了患者个体化因素（如肺功能、合并症）？ | 研究表明，**听诊结果、胸部影像和实验室数据等关键信息的缺失，会显著影响临床决策的效率和准确性**。 |
| **安全与伦理**     | 1. 方案的错误容忍度如何？如何防范误诊/漏诊？<br>2. 是否评估了干预措施（如活检）的风险-受益比？<br>3. 决策是否透明，且考虑了患者价值观？ | 医疗AI提示词设计需**趋近于0的错误容忍度**，                  |

## 五、few-shot prompt：小样本学习的指令，用例子更好教学AI回答逻辑和格式

我们学习经常需要例子辅助学习，更好地形象化我们学习地知识，AI也可以理解为我们的效果，它和我们一样，当我们展示它们例子时也可以非常清晰地把握我们的需要、回答逻辑和书写格式等等。
